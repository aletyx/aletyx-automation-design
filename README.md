# Aletyx Automation Design

[Aletyx Automation Design](https://www.aletyx.ai/experience/) brings decision and process modeling into your IDE — author, run, analyze, and review DMN and BPMN models without leaving your editor.

Available for **Visual Studio Code**, **JetBrains IDEs** (IntelliJ IDEA and compatible), and **Cursor**.

## 📦 Installation

| IDE | Marketplace |
| --- | --- |
| Visual Studio Code | [marketplace.visualstudio.com](https://marketplace.visualstudio.com/items?itemName=Aletyx.automation-design) |
| IntelliJ IDEA and other JetBrains IDEs | [plugins.jetbrains.com](https://plugins.jetbrains.com/plugin/33190-aletyx-automation-design) |
| Cursor, VSCodium, and other Open VSX clients | [open-vsx.org](https://open-vsx.org/extension/aletyx/automation-design) |

Or search for **Aletyx Automation Design** from inside your IDE's extensions view.

## ✨ Features

- **DMN modeling**
  - Edit `.dmn` models for DMN 1.2 through 1.6 in a modern canvas with light and dark themes.
  - Create decision-table-only `.dmns` files alongside standard models.
  - Author FEEL with completion, diagnostics, and go-to-definition across decision logic and data types.

- **BPMN modeling**
  - Edit `.bpmn` and `.bpmn2` files in the React-based BPMN editor.

- **Run models locally**
  - Execute decisions against your own inputs in table or form view, using the bundled local decision engine.
  - Inspect results per row and compare them against expected results.

- **Validate and analyze**
  - Surface validation problems as you model.
  - Detect gaps, overlaps, and missing rules in decision tables.

- **Aletyx AI**
  - Ask for help with your model, and review every AI-proposed edit before applying it.
